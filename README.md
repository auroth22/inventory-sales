# Inventory and Sales System

A web-based inventory and point-of-sale system built with PHP and MySQL.


“Demo account for local testing only”


## How to run
1. Install XAMPP and start **Apache** and **MySQL**.
2. Copy this folder to `C:\xampp\htdocs\inventory-sales`.
3. Open `localhost/phpmyadmin`, click **Import**, and choose `database/inventory_db.sql`.
4. Visit `localhost/inventory-sales/setup_admin.php` once, then delete that file.
5. Visit `localhost/inventory-sales` and log in with `admin` / `admin123`.
